# @whatevertools/utools

Type definitions for plugins that ship to uTools itself: window.utools typings and a plugin.json schema. Zero runtime by default; an optional tiny runtime implements the whatevertools native API on top of window.utools.

这是 [whatevertools](https://github.com/mowtwo/whatevertools) 的一部分，用法和架构见仓库 README。
